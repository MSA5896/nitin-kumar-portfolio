# Project images

Suggested naming: `<project-slug>-hero.jpg`, `<project-slug>-dashboard.png`, `<project-slug>-hardware.jpg`.
Use JPG/WebP for photos, PNG for screenshots and diagrams. Keep each file under ~300 KB.

Reference them in `src/data/projects.js`:
- `image: '/images/projects/smart-ot-environmental-monitoring-hero.jpg'`
- `screenshots: [{ src: '/images/projects/smart-ot-dashboard.png', caption: 'Monitoring dashboard' }]`

Any image left as `null` shows a clean placeholder automatically.
